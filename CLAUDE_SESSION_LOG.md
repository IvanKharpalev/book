Привет! Как запустить mdbook serve?

## Ответ:
Для запуска mdbook serve выполните команду:

```bash
mdbook serve
```

Это запустит локальный сервер (обычно на http://localhost:3000) и будет автоматически перезагружать страницу при изменениях в файлах.

Дополнительные полезные опции:
- `mdbook serve --open` - откроет браузер автоматически
- `mdbook serve --port 8080` - указать другой порт
